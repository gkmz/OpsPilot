## 内容边界

- `docs/notes/`：解释为什么这样设计，以及实现过程中学到了什么。
- `docs/evidence/`：记录具体环境、命令、输出和可复查验证结果。
- `docs/milestones/`：记录版本目标、完成条件和验收状态。
- `docs/adr/`：记录会影响长期架构的正式决策及取舍。
